使用 GitHub Pages + Jekyll 搭建个人博客是一个非常不错的选择，完全免费且稳定。

## 准备工作

在开始之前，你需要：

- 一个 GitHub 账号
- 基本的 Git 操作知识
- 了解 Markdown 语法

## 步骤一：创建仓库

在 GitHub 上创建一个名为 `username.github.io` 的仓库，其中 `username` 是你的 GitHub 用户名。

## 步骤二：配置 Jekyll

在仓库根目录创建 `_config.yml` 文件：

```yaml
title: 你的博客标题
description: 博客描述
theme: minima
```

## 步骤三：写文章

在 `_posts` 目录下创建 Markdown 文件，文件名格式为 `YYYY-MM-DD-文章标题.md`。

## 步骤四：发布

将代码推送到 GitHub 仓库，几分钟后就可以通过 `username.github.io` 访问你的博客了！

## 总结

GitHub Pages + Jekyll 的组合非常适合技术人员搭建个人博客，简单、免费且支持 Markdown 写作。
